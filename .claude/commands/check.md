이 대시보드를 아래 순서로 점검하고, 문제를 심각한 것부터 정리해줘. 코드를 고치지는 말고 보고만 해.

## 1. 숫자 일관성
- 지표를 계산하는 코드가 `src/lib/metrics.js` 밖에도 있는지 찾아줘
- 여러 행을 묶은 지표를 `aggregate()` 없이 평균 낸 곳이 있는지 확인해줘
- 분모가 0이 될 수 있는데 막지 않은 곳을 찾아줘

## 2. 조건 관리
- `useDashboardState` 밖에서 채널·기간·정렬 상태를 들고 있는 컴포넌트가 있는지 확인해줘
- `App.jsx` 말고 다른 곳에서 원본 배열을 다시 거르는 곳이 있는지 찾아줘
- 주소로 들어온 값을 검증 없이 쓰는 곳이 있는지 확인해줘

## 3. 빈 데이터
- 필터 결과가 0건일 때 깨지는 곳이 있는지 확인해줘
- 주차가 1개만 남았을 때 선그래프가 어떻게 되는지 확인해줘

## 4. 빌드
`npm run build` 를 실행해서 통과하는지 확인해줘.

## 5. 미리보기 동기화
`src/` 의 화면과 `preview.html` 의 화면이 서로 다른 부분이 있는지 확인해줘.

$ARGUMENTS 이 어떻게 동작하는지 설명해줘.

나는 마케팅 직무 지망생이고 React를 배우는 중이다. 이 프로젝트를 면접에서 직접 설명할 수 있어야 한다.

설명 방식:

- 전문 용어를 쓸 거면 처음 나올 때 한 문장으로 풀어줘
- 코드 줄을 그대로 읽어주지 말고, **왜 이렇게 짰는지**를 먼저 말해줘
- 이 부분이 없으면 화면에서 무슨 문제가 생기는지 알려줘
- 마지막에 "면접에서 이렇게 말하면 된다" 한 문단을 붙여줘

코드는 고치지 말고 설명만 해줘.

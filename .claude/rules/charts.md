# 차트 작성 규칙

차트는 라이브러리 없이 SVG로 직접 그린다.

## 크기와 반응형

`viewBox` 로 좌표계를 잡고 `style={{ width: '100%', height: 'auto' }}` 로 늘린다. `width`/`height` 속성에 고정 픽셀을 쓰지 않는다.

## 스케일

최댓값은 데이터에서 구하되 최소 500%(`5`)는 확보한다. 필터로 데이터가 줄어도 축이 급격히 바뀌지 않게 하기 위함이다.

```js
const maxVal = Math.max(5, ...data.map(d => d.roas)) * 1.08;
```

## 손익분기선

빨간 점선(`#c0392b`, `stroke-dasharray="3 3"`)을 긋는다. 어떤 채널이 이 선을 넘겼는지 보이는 게 이 화면의 목적이다. 제거하지 않는다. 위치는 `breakevenValue` prop 하나로 받는다 — ROAS 모드는 기본 100%(마진이 있으면 실제로 남는 지점, `1 ÷ 마진율`), ROI 모드는 항상 0%다. 값을 차트 안에서 새로 계산하지 않는다.

## 색

채널 색은 `PLATFORMS` 배열(`src/lib/metrics.js`)에서 받는다. 차트 안에 색상 코드를 새로 적지 않는다. 단, 제품 비교에 쓰는 `CompareBarChart`는 채널 전용이 아니라서 `{id,name,color,desc}` 모양이면 무엇이든 그리는 범용 컴포넌트다 — 이때 색은 `byProduct()`가 돌려주는 제품 팔레트를 그대로 쓴다. 축·격자는 `#e9edf0`, 보조 텍스트는 `#949da8`.

## 엣지 케이스

필터로 데이터가 1건만 남거나 주차가 하나뿐인 경우를 확인한다. 선그래프에서 `weeks.length === 1` 이면 나눗셈이 0이 되므로 가운데에 점을 찍는다.

## 접근성

`role="img"` 와 한글 `aria-label` 을 붙인다. 색만으로 채널을 구분하지 말고 마지막 점 옆에 채널명을 직접 표시한다.

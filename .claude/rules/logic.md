# 계산·상태 로직 규칙

## 지표 계산

지표는 `metrics.js` 에서만 계산한다. 컴포넌트는 계산된 값을 받아 표시만 한다.

**합계를 먼저 내고 나눈다.** 여러 행을 묶은 지표는 `aggregate()` 를 거친다. 주차별 ROAS를 평균 내면 광고비가 적은 주가 과대 반영된다.

```js
// 맞음
aggregate(rows).roas

// 틀림
rows.reduce((a, r) => a + r.roas, 0) / rows.length
```

**0으로 나누는 경우를 막는다.** 필터 결과가 비면 분모가 0이 된다. 모든 지표에 `분모 ? 계산 : 0` 을 유지한다.

## 조회 조건

조건은 `useDashboardState` 하나에서만 바꾼다. 새 조건을 추가할 때:

1. `DEFAULTS` 에 기본값을 넣는다
2. `readFromUrl` 에서 읽고, **범위 밖 값은 무시하거나 보정한다**
3. `writeToUrl` 에서 기본값이면 주소에 넣지 않는다
4. 값을 바꾸는 함수를 `useCallback` 으로 만들어 반환한다

## 정렬

정렬은 원본 배열을 바꾸지 않는다. `[...rows].sort()` 로 복사본을 만든다.

값이 같을 때의 순서를 항상 정해둔다. 기준이 없으면 정렬할 때마다 순서가 달라진다. 이 프로젝트는 동점이면 주차 → 채널 순으로 정리한다.

## 파생 데이터

`App.jsx` 에서 `useMemo` 로 감싸 조건이 바뀔 때만 다시 계산되게 한다. 의존성 배열에 실제로 쓰는 값을 빠짐없이 넣는다.
